## [0.1.0] - 2026-09-27

### Added

- Generate native Socket.IO TypeScript event types from Pydantic-SocketIO AsyncAPI contracts for TypeScript clients and servers.
- Preserve event names, namespaces, payload and ACK types, Pydantic model names, and handler argument names.
- Support Node.js 18, 20, 22, 24, and 26.
