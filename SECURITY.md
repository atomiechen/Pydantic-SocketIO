# Security

Please report a suspected vulnerability in `pydantic-socketio` or `@pydantic-socketio/codegen` through the repository's [GitHub Security Advisories](https://github.com/atomiechen/Pydantic-SocketIO/security/advisories) page using **Report a vulnerability**. Do not open a public issue. Include the affected version and reproduction steps, without credentials or sensitive user data.

Reports about published versions are welcome. The maintainers assess impact and fixes case by case.
